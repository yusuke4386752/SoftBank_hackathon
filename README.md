ココロボ・プロジェクト (Kokorobo Project)
概要
「ココロボ・プロジェクト」は、中高生のグループディスカッションを活性化させることを目的としたAIアバターサポートシステムです。授業内でAIアバター「ココロボ」が思考を深める問いや知識のヒントを提供し、生徒が主体的に意見を形成し、最終的にはその意見を「加工なし」のリアルな声として大津市に届ける仕組みを構築します。

プロジェクトの目的:

中高生の授業内グループディスカッションにおいて、より活発な意見交換を促進する環境を構築する 。


AIアバター「ココロボ」が、各班に1体配置され、思考を深める問いや知識のヒントを提供する 。


生徒が自身の言葉で意見をWebアプリから提出し、市に届ける仕組みを構築する 。


コンセプトの特徴

AIアバターはあくまで“サポート役”: 考えるのは生徒自身であり、AIは「正解」や「提案」を出すのではなく、思考の燃料としての問いやヒントを投げかけます 。




AIの使用回数に制限: 生徒の主体性を促すため、AIの使用回数に制限を設けます（例: 20分の議論で最大3回）。これにより、AIを使うか使わないかの駆け引きが生まれ、議論にゲーム性や戦略性が加わります 。



リアルタイムの文脈対応: 生徒の発言内容をリアルタイムで聞き取り、文脈に沿ったサポートを提供します 。


ターゲット・提供価値
主な利用者
中学生・高校生（授業内でのディスカッション参加者） 

間接的利用者
教員 

大津市職員（集まった生徒の意見を閲覧） 

得られる価値

生徒: 考えのきっかけや問いかけをもらいながら、自分の言葉で意見を出せる。駆け引きのあるAI使用によって、議論が盛り上がりやすくなる 。


教員: AIが議論の膠着を防ぐことで、クラス全体の探究活動の質が向上する 。


大津市: 「要約なし・加工なし」のリアルな声が手に入り、市民の本音を知るきっかけになる 。

機能要件
ディスカッション支援機能

AI発言制御ボタン (FR-002): 使用回数に制限を設け（例: 20分あたり3回）、残り使用回数を常に画面に表示することで戦略性を生み出します 。


AIの発言パターン (FR-003):


🟥 「議論のヒントをもらう」: 深い問いや新しい視点を提示します 。



🟦 「大津市のヒントをもらう」: 市の施策や状況に関する情報を提供します 。



🟨 「具体例をもらう」: 議論している内容の具体例を提示します 。



AI発言の文脈対応 (FR-004): AIは生徒の発言をリアルタイムで聞き取り、その文脈に合わせて適切な問いかけやサポートを行います 。


AIは“正解”を提示しない (FR-005): 結論や答えを直接出すことは避け、あくまで考えるきっかけ、燃料、新しい視点を提供します 。

市への意見提供機能

「そのままの声」提出形式 (FR-006): 生徒自身にWebアプリ上のフォームから意見を提出してもらい、大津市向けのデータベースを提供します 。


データ保存・提出履歴管理 (FR-007): 提出データはクラウドDBに保存され、提出時間、学年、内容が記録されます 。

入力形式: 学年＋意見本文 (例: 中１「誰にも気を遣わなくていい場所がもっと欲しいと思います。」) 

制作方針

ロボットは制作しない: コストと時間の制約、そして本質が「子どもの気持ち・思考を引き出すこと」にあるため、画面上のアバターで目的を達成します 。


対象は「中高生」に限定: 小学生は言語化や音声分析が難しく、中高生は社会課題に関心を持ち始める時期であるため、実用性を考慮し対象を絞っています 。
